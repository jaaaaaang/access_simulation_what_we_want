# 단지 위치 보정 (CAD 추출 단지 → 실제 위치·방위)

CAD(RAPA DXF)에서 뽑은 단지/건물 폴리곤은 모양·축척은 정확하지만, 도면이 임의 좌표라
**위치는 apt_list 대표좌표(오차 최대 ~1km), 방위는 방위표가 없으면 정북 가정**이다.
`src/lib/georef.ts`가 VWorld 공간데이터에서 단지와 같은 모양의 땅을 찾아 맞춘다. (LLM 미사용)

## 기준 데이터 (VWorld Data API)
| 대상 | 레이어 | 비고 |
|---|---|---|
| 지번형(주소에 번지) | `LP_PA_CBND_BUBUN` 연속지적도 | 주소→좌표(getcoord) 필지 + 주변 '대/잡' 필지, 여러 필지 합(재건축) |
| 블록형(택지 L5, A-3 …) | `LT_C_UPISUQ151~159` 도시계획시설 | 도로·녹지·학교 사이 빈 구역 = 블록 (확정측량 전에도 존재) |
| 공통 | `LT_C_UQ111` 용도지역 | 블록=용도지역 폴리곤인 경우 |

## 판정
- 회전 0~360°·이동을 IoU 최대화. high: IoU≥0.9 & 다른 자리 후보와 0.05↑ / medium: ≥0.8 & 0.03↑ (주소 지번 필지면 차이 조건 면제)
- 직사각형 등 **180° 대칭**은 방위 사전정보에 가까운 쪽 선택 + "방향 대칭" 경고 → 화면에서 180° 뒤집기로 확인
- 지목이 하천·도로·전답인 필지는 후보 제외, 지번형은 지번좌표 300m 밖 배치 제외

## 사용
- 로컬: `.env`에 `VWORLD_API_KEY`, `VWORLD_API_DOMAIN`(키의 등록 서비스URL) → `npm run dev`
- 시뮬레이터 도구 탭 **'단지 위치 보정'**: 자동 보정 → 보정안 화면 적용(주황 파선=기준 경계) → 보정 저장(temps JSON, 최초 1회 _backup)
- 자동 실패 시: 화살표(1/5/20/100m)·회전(1°/90°/180°)으로 수동 조정 후 저장
- 사내 배포: Flask 프록시 필요 (`docs/flask_vworld_proxy.md`), 영구 반영은 로컬 저장본 커밋
