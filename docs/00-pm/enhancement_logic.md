# 설명 : enhancement_logic.md

1) 목적은 실제 RF 장비가 건물(APT)를 지향해서 실내 서비스가 잘되어 최적의 위치에서 최소의 장비로 최고의 퍼포먼스를 내기위한 시물레이션 기능을 수행하는 도구를 build하는것이다. 이 도구는 실제 환경과 유사한 환경을 구성할 수 있어야한다.

2) 시물레이션의 정확도를 높이는 방법은 실제 RF 빔 패턴을 기반으로 모델링하고, 건물 구조를 3D 모델링하여 시뮬레이션에 반영하는 것이다.

3) 3GPP 의 로직을 준수하며, 실제 RF 장비의 주파수, 출력, 안테나 틸트각, 빔폭, 빔 방향 등을 설정할 수 있어야한다.

4) **(핵심)현장 설계에서 핵심적이고 직관적인 ground thruth는 실내 서비스가 잘 되기위해서는 O2I가 잘되어야하며, 이를 위한 핵심은 투과가 잘되는 영역 = 베란다를 가장 잘 LOS 하는 위치에서 지향하도록 설계/시물레이션되어야한다.**

5) LOS 정도는 수치적으로 산출함. LOS = (RF가 지향, 커버하는 베란다 길이 합) / (전체 베란다 길이) *100 이다. 
추가설명: first 베란다와 second 베란다가 존재하며, first 베란다가 메인이고 모수에 반영되며, 이를 커버하기 위해 설계한다. second 베란다는 모수에 포함하지 않으나, 부가적으로 RF가 second 베란다를 지향하면 + 가점 해준다. 이때, first 보다 낮은 수치 = 70% 수치정도로 LOS 반영한다. 
이 의미는 second 베란다를 지향하기 위해서 새로운 위치에 장비를 배치하지 않음. 즉, first 베란다를 지향하는 위치에서 추가로 배치할 sector 있다면 sector 추가는 가능. 

6) 장비 위치 = 하나의 site 는 1~3개 Sector = 1~3개 장비로 구성될 수 있다. 

7) 장비는 최대 LOS 합이 높이지도록 함. 가령 건물1을 90% 커버하는 경우와 건물1 60%, 건물2 60%를 커버하는 경우라면 후자를 택해야함.

8) 장비 위치를 선정할때, 가능한 지향하는 건물(들)과 가까이 배치하고, 두 건물이라면 건물들의 중간지점 부근의 지상에 장비를 배치하자.

9) 장비는 가로 막는 건물을 뛰어넘어 서비스를 할수 없음. 단, 장비가 위치하는 건물위에 존재하므로 해당 건물의 벽은 막힌 상태가 아님. (장비는 자기가 위치한 건물의 옥상에 존재한다는 가정, 해당 건물을 직접 서비스할 수 없음.)

10) site 별 = 즉 한장소에 존재하는 1~3개 sector는 동일 PCI(physical cell indicator) 값을 가지며, 시각화에서 동일 color를 가진다. Site별=PCI별로 구별이 잘되는 color로 시각화 하자. 

11) RF 안테나의 Beam Width(°) 기본값은 65°로 설정한다. (Center 각 기준 좌/우 끝 각도는 ±32.5°). 동일 Site 내 Sector 간 중첩이 아예 없으려면 Sector의 Center 각끼리 65° 이상 이격되어야 하지만, 시뮬레이션 및 설계에서는 최소 60° 이격으로 완화 적용한다. (즉, 동일 Site의 Sector 간 최대 5° 정도의 커버리지 중첩을 허용함).

12) 수동 배치 장비(Manual Sector) 삭제 시 Site 전체가 아닌 개별 Sector 단위(예: M-1-A, M-1-B 중 선택한 개별 안테나)로 독립 삭제를 수행할 수 있도록 한다.

13) 시뮬레이션은 사용자의 선택에 따라 다음 3가지 분석 모드를 지원한다:
    - ① **순수 수동 분석 (Pure Manual)**: 사용자가 직접 생성한 수동 Sector만으로 순수 커버리지 분석 (신규 Site 생성 X, 2차 베란다 자동 섹터 추가 X)
    - ② **수동 + 2차 베란다 자동 섹터 (Manual + 2nd Veranda)**: 사용자가 생성한 수동 Sector 기반으로 분석하되, 기존 수동 Site의 남아있는 슬롯에서 2차 베란다를 커버할 수 있는 여분 Sector만 자동 추가 (신규 Site 생성 X)
    - ③ **풀 오토 최적화 (Full Auto Optimization)**: 수동 Sector + 신규 Auto Site 탐색/배치 + 2차 베란다 여분 Sector 추가까지 풀 최적화 시뮬레이션 수행

14) **로직 고도화 및 CAPEX 제약 조건 (Logic Enhancement & CAPEX Constraints)**
    - **① 1차 및 2차 베란다 종합 커버리지 평가**: 단순 1차 커버리지 수치(0m)만으로 섹터 유효성을 판단하지 않으며, 2차 베란다(Second Veranda) LOS 기여도(70% 가점)까지 종합 고려하여 평가한다.
    - **② 핀포인트 미커버 영역 보완 (Auto Assistance)**: Auto 알고리즘은 기존 수동/자동 노드가 덮지 못하는 남은 미커버 구역(예: Building #5 전면 등)을 정확히 포착하여 `AUTO-3-B/C`와 같은 보완 Site/Sector를 핀포인트로 찾아내는 조력자 역할을 수행한다.
    - **③ Target Coverage (%) 달성 시 CAPEX 락 (CAPEX Investment Cap)**: 사용자가 설정한 Target Coverage (%) 목표치에 도달(충족)하는 즉시, CAPEX를 늘리는 신규 투자를 차단한다. (**신규 Site 추가 절대 불가**, 기존 Site 내 제한적 Sector 증설만 상황에 따라 일부 허용).
    - **④ 비효율 섹터 삭감 및 Site Minimize (다이어트)**: 1차 및 2차 베란다 커버 길이가 모두 0m에 가까운 비효율 섹터는 실무상 장비 삭감을 적극 검토하며, 투입되는 Site 및 Sector 수량을 최소화(Minimize)하는 다이어트 로직을 적용한다.
