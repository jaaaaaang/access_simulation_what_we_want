
### 설명
1) 이 프로젝트의 소스 코드 원본(Source of Truth)은 로컬의 다음 폴더입니다: `//Users/1109425/access_simulation_what_we_want`

2) 소스 코드 원본이 업데이트 될 경우, 본 프로젝트로 동기화되어야 하며, 이때, 어떤 기능이 어떻게 개선됭었는지 코드 기준으로 비교 검토를 해야한다. 

3) 비교 검토를 통해서 선별해서 최종 어느기능/어느수준까지 본 프로젝트에 적용할지 결정을 해야한다. 

4) 이를 위해서 본 md 파일을 작성하였다. 

5) gemini는 본 md파일을 이해하고, 소스코드와 현재 프로젝트 코드의 로직/코드를 비교하여 설명한다. (차이점 위주)
